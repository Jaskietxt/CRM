# AutoCRM — стартовый веб-проект

Стартовый интерфейс CRM для автосалона с новыми автомобилями и автомобилями с пробегом.

## Что уже есть
- Светлый русскоязычный интерфейс.
- Боковая навигация по модулям CRM.
- Демонстрационное переключение ролей «Руководитель» и «Менеджер».
- Разные KPI на главной панели в зависимости от роли.
- Разделы клиентов, автомобилей, сделок и задач.
- Общий список клиентов и форма добавления (пока демонстрационная).
- Отдельный экран входа `/login`.
- Адаптивная вёрстка для мобильных экранов.

## Запуск
Требуется Node.js 18.17 или новее.

```bash
npm install
npm run dev
```

Откройте http://localhost:3000

## Важно: текущий статус
Это UI-прототип с демонстрационными данными. Авторизация, сохранение клиентов, серверные права доступа, PostgreSQL и аудит ещё не подключены. Форма входа пока демонстрационная и не обеспечивает безопасность.

## Следующий этап разработки
1. Уточнить страну и валюту.
2. Подключить PostgreSQL и Prisma.
3. Создать модели пользователей, ролей, клиентов, автомобилей, сделок и задач.
4. Реализовать серверную авторизацию и проверку разрешений.
5. Сохранение и редактирование клиентов/автомобилей/сделок.
6. Журнал аудита и резервное копирование.
